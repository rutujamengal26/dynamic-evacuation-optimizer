QUICK GUIDE

How to use the lab

01 · Build the graph

Add rooms and exits, connect them with corridors, then select any element to edit population, walking time or capacity.

02 · Run a scenario

Choose a routing policy and run. People are released in conflict-free waves; the animation is a simplified discrete-time model.

03 · Inject a failure

Enable automatic incident injection or block a corridor while running. The planner recomputes paths for the next planning step.

04 · Compare algorithms

Open Algorithm Lab to benchmark strategies on the same graph. Export CSV for your report and repeat with multiple scenarios.

Safety note

This is an academic simulator, not certified life-safety software. It omits many real-world factors including smoke spread, human behavior, accessibility, fire codes and calibrated crowd dynamics.
